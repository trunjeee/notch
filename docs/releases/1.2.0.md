Голосовой ввод в любое поле: зажал правый Option, сказал, отпустил —
текст напечатался. Работает полностью на устройстве, без сети и сторонних
сервисов.

- **Удерживай правый Option** — чёлка чуть выезжает с красной точкой и
  живой волной из полосок, дышащей в такт голосу. Отпустил — распознанный
  текст печатается там, где стоял курсор. Левый Option остаётся обычной
  клавишей и ничему не мешает.
- **Распознавание — встроенное, от Apple, строго на устройстве**
  (Speech.framework, `requiresOnDeviceRecognition`): аудио не покидает Mac
  вообще. Язык подхватывается сам, из текущей раскладки: русская — диктуй
  по-русски, латиница — по-английски. Пунктуация расставляется автоматически.
- **Длинная диктовка вставляется целиком**, а не хвостом: сегменты речи
  складываются, даже если говоришь с паузами.
- Включается и выключается в меню статус-бара («Голосовой ввод»), по
  умолчанию — включён. При первом нажатии macOS один раз спросит доступ к
  микрофону и распознаванию речи.

И важное для тех, кто собирает приложение сам: сборки теперь подписываются
стабильным self-signed сертификатом вместо ad-hoc, поэтому разрешения
(Accessibility, Input Monitoring, микрофон и остальные) **больше не слетают
при каждой пересборке** — macOS перестаёт считать каждый билд новым
приложением. Сертификат создаётся один раз скриптом
`Scripts/setup-signing.sh`.
