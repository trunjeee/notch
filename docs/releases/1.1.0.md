Свои слова для переключателя раскладки, и список исключений теперь можно
редактировать по-настоящему.

- **Свои слова** — новый список («Свои слова…» в меню статус-бара): слова,
  которые всегда считаются настоящим английским, даже если системный словарь
  их не знает — свой домен, бренд, ник. Без этого короткие небиблиотечные
  слова вроде домена не исправлялись ни в одну сторону.
- Список исключений и список своих слов теперь можно **редактировать и
  удалять** по каждому слову отдельно (были только «добавить» — на macOS
  свайп для удаления не работает так, как на iPhone).
- Починен скрытый баг: полностью очищенный список исключений раньше тихо
  восстанавливал стандартные значения при следующем запуске.
