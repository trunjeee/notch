Исправлены две назойливые ошибки переключателя раскладки:

- Буквенно-цифровые куски вроде hex-кодов («f5», «b2b») больше не портятся —
  одинокая буква рядом с цифрой раньше ошибочно принималась за слово из
  одной буквы и заменялась на кириллицу.
- Стрелки при навигации по автокомплиту (и другие служебные клавиши) больше
  не допечатывают мусорный символ в текст.
