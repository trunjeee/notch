Первый релиз форка **Notch by trj**, на основе [Cyclop](https://github.com/akalikbergenov/cyclop).

Новое поверх оригинала:

- **Переключатель раскладки RU/EN** — исправляет слово на лету, когда оно набрано не в той раскладке, чинит пропущенную «ё», ставит запятую перед «который»/«но»/«а», знает частые технические аббревиатуры (js, css, html...). Автокоррекция опечаток — отдельным переключателем, список слов-исключений редактируется в приложении.
- **System** — загрузка CPU и памяти с топ-процессами, индикатор нагрузки на память.
- **Network** — скорость сети и топ-приложения по трафику.
- **Power** — заряд Mac и подключённых Bluetooth-устройств.
- **Reminders** — задачи из выбранных списков, отметка выполненным.
- **Quick Actions** — запуск команд Shortcuts из панели.
- Свои иконки приложения и статус-бара.
- Режим приватности **Hide Contents** расширен на все новые вкладки.
