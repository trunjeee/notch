# Notch by trj

*[English](README.md) · Русский*

Нативное приложение на SwiftUI/AppKit для строки меню, которое превращает
чёлку MacBook в рабочую панель — в покое незаметно, при наведении курсора
разворачивается в плеер, полку для файлов, историю буфера обмена, заготовки,
ближайшие встречи, перевод и черновые заметки — плюс автопереключатель
раскладки RU/EN и несколько вкладок мониторинга системы и продуктивности
поверх этого.

macOS 15 или новее. Полностью локально: без аккаунтов, серверов и телеметрии.

## Основа — Cyclop

Это приложение начиналось как форк **[Cyclop](https://github.com/akalikbergenov/cyclop)**
за авторством [akalikbergenov](https://github.com/akalikbergenov), выпущенного
под лицензией MIT. Cyclop — это сама панель в чёлке: плеер, полка для файлов,
история буфера обмена, заготовки, календарь, офлайн-перевод и черновые
заметки — вместе с низкоуровневой механикой, которая заставляет панель без
рамки и с «сквозными» кликами вести себя как родная часть macOS: определение
наведения курсора, геометрия окна, привязанная к реальному размеру чёлки,
поведение курсора и мост к Now Playing, читающий информацию о треке из любого
приложения, которое видит сама macOS.

Ничего из этой механики здесь заново не пересказывается. В README оригинала
подробно разобрано, как и почему всё это работает — устройство окна,
click-through hit-testing, хелпер для Now Playing, дисциплина таймеров,
которая держит приложение на 0% CPU в покое, и многое другое.
**[Читайте это в первоисточнике](https://github.com/akalikbergenov/cyclop)**,
если хочется полной картины — там действительно хорошо задокументированный код.

Лицензия MIT разрешает форку переименовывать, менять и распространять код
свободно — именно это здесь и произошло: код переименован целиком, иконки
приложения и статус-бара свои, а разделы ниже описывают, что добавлено
поверх. Оригинальное уведомление об авторстве и копирайт сохранены в
[`LICENSE`](LICENSE) — так требует MIT.

## Что добавлено здесь

| Вкладка | Что делает |
|---|---|
| **Переключатель раскладки RU/EN** | Слово, напечатанное не на той раскладке, исправляется на месте — стирается, перепечатывается на нужном алфавите, раскладка переключается — в момент завершения слова, через системный словарь, а не догадку. Также чинит пропущенную «ё» в частых словах, ставит запятую перед «который»/«но»/«а», если её не хватает, и знает небольшой список технических аббревиатур (`js`, `css`, `html`, ...), которые не являются словарными словами. Рядом — необязательная автокоррекция опечаток внутри одного языка, выключена по умолчанию. Оба переключателя независимы, через иконку в строке меню, там же — редактируемый список слов-исключений |
| **System** | Загрузка CPU (user/system/idle) и памяти, у каждого — топ-5 процессов, плюс индикатор нагрузки на память, как в самой Activity Monitor |
| **Network** | Скорость приёма/отдачи и приложения, которые реально её расходуют — тем же способом, каким это делает вкладка Network в Activity Monitor |
| **Power** | Заряд самого Mac, и подключённые Bluetooth-устройства (наушники, мыши, клавиатуры) с их зарядом там, где железо его вообще сообщает |
| **Reminders** | Что нужно сделать — из одного списка, нескольких или всех сразу, выбор — прямо во вкладке. Клик отмечает выполненным |
| **Quick Actions** | Запуск любых команд Shortcuts из панели — выбираешь, какие показывать, запускаешь кликом |

Всё перечисленное подчиняется уже существующему режиму приватности
**Hide Contents** — каждую новую вкладку можно скрыть отдельно, как уже было
устроено для Clipboard, Snippets, Calendar и Notes.

### Про переключатель RU/EN

Публичного API «эта раскладка не та» не существует — используется тот же
принцип, на котором сами раскладки построены: обе занимают одни и те же
физические позиции клавиш, поэтому слово, набранное не в той раскладке,
можно пересчитать через таблицу другой раскладки и проверить системным
словарём. Если набранное — не настоящее слово в текущем языке, а
пересчитанное — настоящее слово в другом, происходит исправление. Требует
разрешений **Accessibility** и **Input Monitoring** — это те два разрешения,
без которых глобальная коррекция клавиатуры принципиально невозможна.

### Про заряд Bluetooth-устройств

У Apple нет публичного API для процента заряда подключённого аксессуара.
`IOBluetoothDevice` несёт несколько недокументированных методов
(`batteryPercentSingle`, `headsetBattery` и другие), которые внутри себя
читает собственное меню Bluetooth у Apple — приложение вызывает их так же,
но перед вызовом проверяет реальную Objective-C сигнатуру каждого метода,
а не угадывает её, потому что вызов метода, возвращающего примитив, как
будто он возвращает объект — именно так подобные трюки роняют процесс.
Требует разрешение **Bluetooth**.

## Установка

Открой `.dmg` и перетащи приложение в Applications. При первом запуске
macOS скажет, что не может проверить приложение — это ожидаемо, сборка
подписана ad-hoc, без платного Apple Developer ID. В **System Settings →
Privacy & Security** внизу появится кнопка **«Открыть в любом случае»**
после первой попытки.

Дальше macOS будет спрашивать разрешения по одному, только когда
понадобится конкретная функция: **Accessibility** и **Input Monitoring**
(переключатель RU/EN), **Bluetooth** (заряд устройств), **Reminders**,
**Calendar**. Ничего не запрашивается при запуске — только по кнопке или
при открытии нужной вкладки.

Так как сборка подписана ad-hoc, а не стабильным Developer ID, каждая
пересборка меняет подпись, и macOS считает это новым приложением с точки
зрения разрешений — после обновления их придётся выдавать заново, пока
не появится подпись настоящим сертификатом.

## Сборка

```bash
git clone https://github.com/trunjeee/notch.git
cd notch
./Scripts/bundle.sh          # swift build + сборка .app + ad-hoc подпись
open "build/Notch by trj.app"
```

```bash
./Scripts/dmg.sh             # то же самое, плюс .dmg с ярлыком /Applications внутри
```

Нужен macOS 15+ и тулчейн Swift 6 (достаточно Command Line Tools, полный
Xcode не требуется).
