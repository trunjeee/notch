# Notch by trj — инструкция по установке

## 1. Установка

1. Открой `notchbytrj-1.0.0.dmg`
2. Перетащи **Notch by trj** в папку **Applications**
3. Открой `Applications`, найди **Notch by trj**, кликни **правой кнопкой мыши → Open** (не двойным кликом левой!)
4. Появится предупреждение «Apple не может проверить...» — нажми **Open**

Это разовая история — дальше приложение открывается как обычное. Причина: сборка без Apple Developer ID (платной подписки), поэтому Gatekeeper по умолчанию блокирует первый запуск.

Если шаг 3 не сработал (в новых macOS иногда нет опции через правый клик):
- Открой **System Settings → Privacy & Security**
- Прокрути вниз, найдёшь строку про заблокированное приложение «Notch by trj»
- Нажми **«Открыть в любом случае»**

## 2. Разрешения

При первом запуске и при первом открытии некоторых вкладок macOS будет спрашивать разрешения. Всем нужно сказать **да / разрешить**:

| Разрешение | Для чего |
|---|---|
| **Accessibility** | Переключатель раскладки RU/EN — без этого не может печатать исправления |
| **Input Monitoring** | Переключатель раскладки RU/EN — без этого не видит, что ты печатаешь |
| **Bluetooth** | Показ подключённых наушников/мыши/клавиатуры и их заряда |
| **Reminders** | Вкладка Напоминаний |
| **Calendar** | Вкладка Календаря (спросит только если откроешь эту вкладку) |

Все разрешения — в **System Settings → Privacy & Security**, там отдельный раздел на каждое. Если диалог не появился сам — зайди туда и добавь «Notch by trj» вручную через «+».

⚠️ **Важно:** если приложение потом обновится (новая версия/пересборка), эти разрешения слетят и их нужно будет выдать заново — так работает подпись без Developer ID.

## 3. Как пользоваться

Наведи курсор на вырез экрана (чёлку) сверху — появится панель. Слева — основные вкладки (Музыка, Полка для файлов, Буфер обмена, Заготовки, Календарь, Перевод), справа — вкладки поменьше (Напоминания, Заметки, Быстрые действия, Система, Сеть, Питание).

### Переключатель раскладки RU/EN
Работает сам, автоматически — печатаешь слово не на той раскладке, оно на лету исправляется + переключает раскладку + звук. Настройки — через иконку в строке меню сверху экрана (значок приложения) → там:
- **RU/EN Layout Switcher** — вкл/выкл
- **Spelling Autocorrect** — отдельно, исправление опечаток внутри одного языка (выключено по умолчанию, можно включить)
- **Switcher Exceptions…** — список слов, которые никогда не трогать (свои имена, домены и т.п.) — можно редактировать прямо в окошке

### Reminders (Напоминания)
Иконка фильтра справа сверху — выбрать конкретный список задач или «Все списки».

### Quick Actions (Быстрые действия)
Кнопка «+» — добавить любую из своих команд Shortcuts (macOS Shortcuts.app), дальше просто клик по строке запускает её.

### System / Network / Power
Загрузка процессора и памяти (с топ-процессами), скорость сети (с топ-приложениями), заряд батареи Mac и подключённых Bluetooth-устройств.

### Приватность (Hide Contents)
В том же меню статус-бара — пункт **Hide Contents**, можно скрыть содержимое любой вкладки по отдельности (для скринкастов/трансляций).

## 4. Яндекс.Календарь (если нужен)

Если хочешь видеть события Яндекс.Календаря в приложении — добавь его как учётную запись в самой системе (не в этом приложении):

1. **System Settings → Internet Accounts → Добавить другую учётную запись → CalDAV**
2. Сервер: `caldav.yandex.ru`, логин и пароль (или app-пароль) от Яндекса
3. Готово — вкладка **Calendar** в приложении подхватит его сама

Если через мастер не добавляется (бывает с сертификатами у российских сервисов) — попробуй ввести данные вручную тем же способом, либо используй публичную ссылку календаря (webcal/ICS) как подписку в системном Calendar.app.
